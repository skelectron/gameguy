Quick decision guide

  • "I want to ship my first 2D game this year, and I'm an artist." → GameMaker or Godot.
  • "I want a 3D game with a big asset ecosystem and console plans." → Unity (or Godot, depending on scope).
  • "I'm a programmer and want to understand everything, or build my own engine." → BRUTAL.
  • "My game is a huge simulation (colony, space, logistics) and needs to run for 10 years." → BRUTAL, which is the RimWorld/Waylith and Kitten Space Agency path.
  • "I'm in a game jam this weekend." → Whatever you already know best.

Skills that transfer everywhere

Whatever you choose, these lessons apply: the fixed timestep, value vs reference types, components and ECS, game feel and pixel-art fundamentals. Learning BRUTAL makes you better at every engine, because you'll understand what they do behind the scenes.

GAMEGUY'S RECOMMENDATION

Learn on BRUTAL to understand how games work. Prototype ideas in whatever is fastest for you. Ship using the tool that fits the game.
