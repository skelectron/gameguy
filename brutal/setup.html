Setup: .NET 10, GPU & samples

You will learn
  • What you need installed to use BRUTAL
  • How to clone the repo and run its single-file samples
  • How #:package directives pull in NuGet packages

Requirements

NeedWhy
.NET 10 SDKBRUTAL targets .NET 10. It also gives you dotnet run file.cs with no project file.
Windows x64, Linux x64, or macOS on Apple siliconThe packages bundle native libraries for these three platforms.
A Vulkan 1.3 GPU with current driversOnly needed for rendering. OpenGL samples run at 4.1.
Vulkan SDK (optional)Validation layers while you develop. Required on macOS, where it provides the loader and MoltenVK.
GitTo clone the repository and its samples.

Linux extras

Install a Vulkan loader and driver, for example libvulkan1 and mesa-vulkan-drivers on Debian or Ubuntu. Windowed samples need an X11 or Wayland session, and the native file dialog needs GTK 3.

1. Install .NET 10

Download the SDK from dotnet.microsoft.com, then check it works:

2. Clone BRUTAL

The top-level folders (Brutal.Core, Brutal.Glfw and so on) hold the library sources. The samples/ folder is where you'll spend most of your time early on:

  • samples/Hello/ has one tiny sample per package. Each is the smallest useful starting point for that package.
  • samples/Demo/ has fuller programs that combine several packages, such as the Box2D demo, the textured quad and the glTF viewer.

3. Run a sample

That's it: a single .cs file with no .csproj. .NET 10's file-based apps feature reads special directives at the top of the file:

  • #:package Name@Version is a NuGet package reference, which dotnet run restores automatically.
  • #:property Key=Value is an MSBuild property. Samples that use pointers turn on AllowUnsafeBlocks.
VERSIONS

BRUTAL packages use calendar versions such as 2026.10.4. Different packages can be on different versions. Copy the exact versions from the current samples in the repo, because they are known to work together.

Editor setup

Any C# editor works: VS Code with the C# Dev Kit, Visual Studio 2026 or JetBrains Rider. Two tips:

  • Keep the BRUTAL repo open in a second window, because reading the sample code is the best documentation there is.
  • Install RenderDoc early. BRUTAL has Brutal.RenderDoc integration for capturing GPU frames.
