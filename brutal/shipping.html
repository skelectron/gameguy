The license in plain English

BRUTAL is distributed under the BRUTAL License v1.0, which is based on MIT. You may use, copy, modify, merge, publish, distribute, sublicense and sell software that uses it, with no royalties. The extra conditions apply when you ship a Product, meaning a game or application distributed to end users:

ClauseWhat you must do
2.1 CreditsShow the BRUTAL copyright notice in your Credits screen or equivalent.
2.2 LogoShow the BRUTAL logo (from ahwoo.com/brutal-branding) before gameplay or the app's main function. Don't alter it except by scaling. Show it long enough to read, and at least as prominently as any other party's logo.
2.3 NOTICEShip NOTICE.txt alongside all copies.

Exemptions from the logo rule: written permission from Ahwoo, products that can't display graphics, non-profit projects, and cases where the logo would harm the application's purpose. A separate commercial licence can also be arranged with Ahwoo.

Third-party components (GLFW, SDL, Box2D, ImGui and so on) keep their own licences. These are listed in the LICENSES/ folders of the packages that redistribute native code, and you should include them too.

The output goes to bin/Release/net10.0/<rid>/publish/. The BRUTAL packages bring their native libraries for these three platforms, so check that the native .dll/.so/.dylib files ended up next to your executable.

A file-based app (CoinDash.cs) can be turned into a project at any time with dotnet project convert CoinDash.cs.

Optional: Native AOT

Adding -p:PublishAot=true compiles your game to native code, which gives faster startup and no JIT. Test it thoroughly, because reflection-heavy code may need changes. BRUTAL's own interop layer is designed for direct native calls.

Release checklist

  • ☐ BRUTAL logo shown before gameplay (or you qualify for an exemption)
  • ☐ Copyright notice in the credits
  • ☐ NOTICE.txt and third-party LICENSES shipped with the build
  • ☐ Tested on a clean machine with no SDK installed
  • ☐ Tested at several window sizes and refresh rates (60/144 Hz) to confirm the fixed timestep works
  • ☐ Logs are written to a user-writable folder, not the install folder
  • ☐ Controller support, if you claim it, works through GLFW/SDL gamepads
