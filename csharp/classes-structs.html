Classes, structs & records

This is the most important C# lesson for game performance. The difference between a class and a struct decides where your data lives, how it is copied, and whether the garbage collector has to deal with it.

Reference types (class)

Value types (struct)

When you loop over 10,000 particles, the struct array is read from memory in one sequential stream, which is very cache-friendly. The class array makes the CPU jump around memory for every element, and the GC has to track 10,000 separate objects. This is the core idea behind ECS / data-oriented design.

When to use which

Use a struct when…Use a class when…
It's small data: vectors (float2), colours, rectangles, particles, componentsIt has identity and a lifetime: a window, a scene, a game service
You store many of them in arraysIt's shared and referenced from many places
Copying it is cheap (roughly ≤ 32 bytes is a common guideline)It's large or needs inheritance
