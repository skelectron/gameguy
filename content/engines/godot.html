Mental model: nodes and scenes

Everything is a node (Sprite2D, CollisionShape2D, Timer…). Nodes form a tree, and a saved tree is a scene. A scene can be placed inside other scenes, so a "Player" scene can be used in every level scene. Nodes talk to each other through signals, which work like C# events.

A platformer player in C#

Compare this with Coin Dash. _PhysicsProcess is the engine's fixed timestep, Input.IsActionJustPressed is an input map like the one in the engine track, and MoveAndSlide replaces the hand-written MoveX/MoveY. Godot calls your code, which is the inversion of control described in Engine vs framework.
