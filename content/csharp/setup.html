  1. Download the .NET 10 SDK from dotnet.microsoft.com/download.

Your first file-based app

.NET 10 can run a single .cs file, with no project or solution. This makes small experiments almost free:

This is called top-level statements: the file itself is your Main method. You can still declare functions, classes and structs below the statements.

Directives

Lines beginning with #: configure the app. They're how every BRUTAL sample pulls in packages:

  • #:package adds a NuGet package reference.
  • #:property sets a build property, such as enabling unsafe code.
