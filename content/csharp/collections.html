Span<T>: a window into memory

Span<T> is a view over memory that is next to each other. That memory can be an array, part of an array, stack memory or native memory. A span is a tiny struct (a pointer plus a length) and it never allocates.

BRUTAL APIs use spans everywhere. Mem.AllocZeroed<int>(…) returns a span over native memory, NativeList.AsSpan() exposes the list, and OpenGl.BufferData accepts spans of vertices. If your code works with Span<T>, it works with all of them.

SPAN RULES

A Span<T> is a ref struct. It can only live on the stack, so you can't store it in a class field or capture it in a lambda. When you need to store a view, use Memory<T>, or keep the array and an offset.
