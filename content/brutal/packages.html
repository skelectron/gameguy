Tour of the packages

BRUTAL is about 48 small libraries. You'll never use all of them in one game. Choose the ones you need, the way you'd pick from a toolbox. Every folder Brutal.X in the repo is published as the NuGet package Ahwoo.Brutal.X.

GLFW OR SDL?

For a 2D pixel game, choose SDL: its renderer draws textured sprites and rectangles with no shaders needed. Choose GLFW when you'll write your own renderer in OpenGL or Vulkan. This course teaches both.

Recommended learning order

This follows the official samples README:

  1. Foundations: HelloCore, then HelloMemory, HelloCollections and HelloStrings
  2. Windowing: HelloGlfw, then HelloImGui
  3. Graphics: HelloOpenGl for a triangle, or HelloVulkan then DemoVulkan
  4. Audio: HelloOpenAl
  5. Physics: HelloBox2D or HelloJolt, then their demos

The rest of this track follows that order, with a detour into SDL for pixel-perfect 2D.

READ THE "RIAN" COMMENTS

Many samples contain // RIAN: notes from the maintainers, such as "This package is due for a big update for custom allocators." They tell you which APIs are stable and which are about to change. Read them!
