Debug UI with Dear ImGui

You will learn
  • What "immediate-mode" UI means and why engine developers love it
  • How to wire up the GLFW and OpenGL backends from Brutal.ImGui.Backends

  • How to build a live "tweak panel" for gameplay values

Dear ImGui is how most studios build in-game debug tools and editors. There are no widget objects to manage. Every frame you just describe the UI in code:

If the button was clicked this frame, Button returns true. The slider writes straight into your variable. That's the whole model.

Setup

The per-frame pattern

DON'T SKIP SHAREDSTORAGE.RESET()

Interpolated strings passed to ImGui ($"spawned {spawnCount}") are formatted into a shared scratch buffer, so they don't allocate. The maintainers warn: the shared storage "will OoM eventually if you don't" reset it. Call ImString.SharedStorage.Reset() once per frame, right after ImGui.NewFrame().

Uses beyond debugging

  • Level editors: ImGui's docking branch, which BRUTAL binds, can build a full editor layout.
  • Graphs: Brutal.ImPlot for frame-time graphs and economy curves.
  • Nicer fonts: Brutal.ImGui.FreeType (see DemoImGui.cs).
  • GPU captures: Brutal.RenderDoc.ImGui adds a "capture frame" button.
