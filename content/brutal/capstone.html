Capstone: Coin Dash

You will build
  • A complete single-screen platformer in a single file of about 200 lines
  • A tile map from strings, AABB collision resolved one axis at a time
  • Responsive controls: acceleration, coyote time, jump buffering and variable jump height
  • A HUD, a win state and a restart key

This brings the whole track together: the fixed-timestep loop, SDL's integer-scaled renderer and game-feel techniques. Everything is drawn with rectangles, so you need no asset files. Swapping in real sprites is your first upgrade.

The full game

Run it with dotnet run CoinDash.cs.

How it works

Collision one axis at a time

Move along X, and if the player now overlaps a solid tile, push them back to that tile's edge. Then do the same for Y. Resolving each axis separately tells you which side you hit: landing on a floor (Y, moving down) sets onGround, and hitting a ceiling stops upward speed. At these speeds (at most 400 px/s, so under 7 px per step) the player can never skip through a 16 px tile. That's another benefit of a fixed timestep.

The three "forgiveness" tricks

TrickProblem it solvesCode
Coyote timeThe player presses jump a few frames after running off a ledge, and nothing happens.coyote stays positive for 0.08 s after leaving the ground
Jump bufferThe player presses jump just before landing, and the press is ignored.jumpBuffer remembers the press for 0.1 s
Variable heightEvery jump is the same height, so it feels floaty and hard to control.Releasing jump early caps upward speed (JUMP_CUT)

Players never notice these tricks; they just say the controls "feel good". Read more in Game feel & juice.

Upgrades (do them in order)

LEVEL UP
  1. Sprites: draw a 16×16 hero with 4 run frames in the pixel editor. Load it with SdlImage.LoadTexture, use SdlScaleMode.Nearest, and pick the frame from time. To face left, call Sdl.Render.RenderTextureRotated(r, tex, &src, &dst, 0, null, facingLeft ? SdlFlipMode.Horizontal : SdlFlipMode.None).
  2. Sound: use the generated coin and jump sounds from the audio lesson, or Sdl.Mixer as in DemoSdl.cs.
  3. Juice: squash and stretch on landing, a few dust particles, and a 2-frame freeze when grabbing a coin.
  4. Levels: move Level into text files and load the next one when won.
  5. No per-frame garbage: the HUD's $"..." allocates a new string every frame. Cache the string and rebuild it only when score changes, or format into a Span<char>.
  6. Credits: add a title screen showing the BRUTAL logo and a credits screen with the BRUTAL copyright notice. See Shipping.
